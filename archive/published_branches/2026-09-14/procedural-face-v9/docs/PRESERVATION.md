# Source preservation

The prior v3, reference-v2 and first concept archives are retained as extracted payloads. Transport ZIPs duplicating those files are not themselves committed. The original illustration is retained as a labeled concept reference, never used as a substitute for rendered geometry.

The old source files remain in their original directories for provenance. The new `src/cybrgeo` package is separate and does not mutate archived solver or geometry files. Old recorded footage is distinguished from the newly generated motor media. File-level checksums identify the preserved payload.

The source model's dimensions and image labels are not load ratings. This repository contains design studies, inspection assets and prescribed kinematic motion. Use a qualified engineering review before building or energizing hardware.
